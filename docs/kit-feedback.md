# game-kit への要望（八尺様の載せ替えで見つけたこと）

> 2026-10-31：標準 1.7（game-kit `claude/standard-1.6` ブランチ、Game-fleet#44）で 1〜7 を標準に入れ、作品側の回避を外した（`ext.registerLook`、屋外の縁と開口・二重の壁、`plan-check` の屋外の輪、`ctx.talk` / `ctx.choose`、`timer`、`car({ interior: true })`）。夜（L3）と車（L5）は死に方などの作品のルールがあるため、時間の進め方は作品側に残している。

game-kit には書き込めなかったので、作品側で吸収した点を残します。game-kit を直したら、作品側の回避を消してください。

1. **怪物の見た目を作品が登録する API がない。** `monsters.schema.json` の `look` は `windmill | dark-red-mist` だけ。八尺様は `LOOKS['dark-red-mist']` を差し替えている（`js/ext/hasshaku.js`）。`ext.registerLook(name, fn)` と、スキーマの `look` に作品の名前を許すことを提案。
2. **屋外の部屋に壁が立つ。** `world-from-plan` は `kind: outdoor` にも 3 m の壁を建てる。村のような屋外の地図では、壁を見えなくして生垣・杉の列に置き換えている（`js/ext/village.js`）。`outdoor` の外周は「当たりだけ／見た目は作品が決める」を標準に。開口だけの扉（`open: true`）も、扉の板を作らない指定がほしい。
3. **二つの部屋の境の壁が二重になる。** 隣り合う部屋が同じ位置に壁を作る（W6 のちらつきの原因になりうる）。作品側で片方を消している。
4. **plan-check の `no-loop` は廊下だけを数える。** 屋外の道が輪になっている村の地図では誤検出になる（`--ignore=no-loop` で回避）。`outdoor` も通路として数えてほしい。
5. **会話（立ち絵・話者・次へ）の標準部品がない。** `win-manager` の窓に作品で組んだ（`story.js` の `talk()`）。チャット標準とは別に、3D の会話窓を標準に。
6. **台本の時間で進むタスク**（夜が明ける、車が着く）は、smoke が待てない。作品は `?qa` で 10 倍速にした。標準に「時間で終わるタスク」の型と、テスト用の早送りの決まりを。
7. **車の標準モデル（`env-props.car`）に内装がない。** 乗車の場面のために、作品で内装を組んだ。
