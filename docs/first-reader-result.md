# 初見の読み手テストの結果

手順は Game-fleet の docs/first-reader-test.md。読み手は2回とも新しいサブエージェント。このゲームには spec/ がない（元は v4 の単一 HTML）ので、事実はゲームの中の文（道守りの覚え書き、村の控え、尋ね人、切り抜き）から取った。

## 判定

- **1回目：前提は言えたが、動機と説明に穴があり不合格。** 第一章のあとに「2008年の夏、私が母の代わりに祖父母の村へ来て、白い帽子を見た」は言えた。残った穴は、なぜ母の代わりに来たのか、Ｋさんは誰か、声で信じて戸を開けたのに「誰の声でも開けるな」と言う食い違い、返事の禁止が指示にないこと、祖母がいないこと、なぜ村境で助かるのか、Ｋさんと祖父がなぜ一緒に行かないのか。最初に分からなくなった行は「写真の裏と同じ年だ。」（寄り道をしなければ「Ｋさんを呼ぶ。」）。
- **2回目：合格の目安は満たす。** 誰が、どこで、何をしているか、声の仕組み、選択肢の得失を自分の言葉で言えた。「こちらから開ける」の約束で偽物を見破る流れは分かりやすいと言った。残った大きな指摘を直した：Ｋさんが一緒に歩かない理由、走る・走らないの食い違い、まだ見ていない人のことを先に書いていた目標、見たものの言い方、小皿の場所、母が村を出た理由と写真の裏の一文、桃の箱の送り主。再テストは1回だけの決まりなので、直したあとの文は読み手に通していない。

## 仕様書にない、足した事実（ユーザーの確認待ち）

- 主人公は大学一年生（1998年に「まだ小さかった」と2008年の夏休みをつなぐ）。性別と名前は決めていない。
- 母はこの十年、村へ帰ろうとしない。主人公が代わりに来た。母は「一泊だけ」と念を押した。
- Ｋさんは「こういう時に札を書いて、村の外へ送り出してくれる人」（村の控えの「札を持たせ、村境の外へ送り出す」から）。何者かはこれ以上言わない。
- 玄関でＫさんを信じた理由は、声ではなく戸の隙間から入れた札（「声だけなら信じんが、これは真似できん」）。
- 札は「持ち主の身代わりになる」。
- 「見つめて、向こうに気づかれた。見入られた、と言う」。見入られると親しい人の声で名を呼ばれ、返事をした人は数日のうちに居なくなった（村の控えを会話でも言う）。
- 祖母は夕方、親戚の家へ用足しに出た。祖父が電話で朝まで戻るなと伝えた。
- 「村の四方の地蔵の外へは出られないと言われている」（控えの「女を村の内に留めた」から。「言われている」にして断定しない）。
- 車止めは木の門で、村の内側からしか開かない。二人で歩けば足音が増えるので、Ｋさんは先に外の道を回り、門の向こうに車をつける。祖父が残るのも「見入られたのはお前だけ。足音が増える」から。
- 「村を出たら、もう戻らないで。戻れば、また見つかる」（控えの「呼び戻してはならない」の理由）。
- 写真の裏に「一九九八年 八月」。
- 結末「写真を持って」：1998年の夏に村で男の子がいなくなり、同じ夏に母は生垣の上に白い帽子を見た。それで主人公を連れて村を出て帰らなかった。写真の裏の一文は、母が自分に書いたもの。
- 結末「帰れない家」：母は「十年、何もなかったから、一泊なら大丈夫だと思った」と頭を下げる。桃の箱は祖父の家から届く。

## 変えた文（食い違いの解消）

- 店のおばさん「社のほうに寄らず」を「社のところで立ち止まらずに」に（店は社の先にある）。
- 「知らない人が庭に入ったなら」を「近くの空き家にいるなら」に。
- 目標「祖父に、見たものを話す」を「祖父に、買った物を届ける」に（見る前に出ていた）。第1段階のあらすじも同じ。
- 祖母の手紙「窓際にある小さなお皿」を「部屋の隅にある」に（皿は四隅）。
- 覚え書き「境を越えたら終わり、とは伝えないこと」を「「もう大丈夫」とは伝えないこと」に。村の控え「盆を過ぎた夕方」を「盆のころの夕方」に（尋ね人は8月14日）。
- 「車止めが上がる」をやめた（門は左右に開く）。「右側の戸」を「右側の後ろの戸」に。
- 「アスファルトがまだ昼の熱を持っている」を第1段階だけに（朝にも出ていた）。
- 「ライトが……止まらないで」を「霧なのに、ライトが消えた。……でも、車は止めないよ」に。
- 祖父の指示に「返事をするな」を足した。祖父の朝の指示に「見つかるまでは歩け」を足した。追われるときの字を「小屋か物陰へ隠れろ」に。
- Ｋさんの朝の第一声を「七時になった。いま、こちらから開けるよ」に（約束どおりに開けると分かるように）。

## 直していない指摘

- 八尺様の正体、なぜ親しい声を真似るのか、なぜ札や塩が効くのか、なぜ時計が戻ったのか：怪異の正体に関わるので断定しない。
- 裏返しの位牌、鴨居より高い名前のない傷、家の奥の足音、何度も夜を数えた印：残した。「祖父に聞けなかった」「誰が」と、分からないまま残したと読める文になっている。
- 「私たちは、鍵の場所を知っている」「こちらには、取りに来なくていいからね」：余韻として残した。怖かった所に挙がった。
- 空の塩袋の「毎年の夏」と失踪の年の間隔、祖母の手紙の「冷蔵庫」とかまどの作りかけ：読み手の小さな引っかかりで、話を読む妨げではない。
- 駐在への連絡のその後：触れていない。
- 章1の「お母さんが見入られたのか」：結末「写真を持って」でだけ帽子を見たと言い、見入られたとは言わない。
